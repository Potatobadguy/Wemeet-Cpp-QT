## 每个文件怎么看

1. **先读头文件（.h）**：看类的公开接口、数据成员、注释
2. **再读实现文件（.cpp）**：看算法细节、资源管理
3. **最后看测试（tests/）**：看怎么用这个类

遇到不认识的 C++ 特性，**停下来先学那个特性再看回来**，比硬啃有效得多。

## 核心 C++ 技术点速查

| 技术 | 使用位置 | 一句话解释 |
|------|----------|-----------|
| **移动语义** `&&` | Buffer, Socket | 把资源从一个对象"偷"到另一个，避免拷贝 |
| **RAII** | Socket, ConnectionPool, Buffer | 构造时获取资源，析构时自动释放 |
| **智能指针** | TcpConnection (shared_ptr), Buffer (unique_ptr) | 自动管理对象生命周期 |
| **thread_local** | MemoryPool | 每个线程一份独立数据，零锁竞争 |
| **std::atomic** | LockFreeQueue, Logger, EventLoopPool | 无锁的线程安全计数和状态 |
| **memory_order** | LockFreeQueue | 控制多线程间数据的可见性顺序 |
| **alignas(64)** | LockFreeQueue | 缓存行对齐，消除伪共享 |
| **std::function + lambda** | EventLoop, TcpServer | 灵活的回调机制 |
| **enable_shared_from_this** | TcpConnection | 在回调中安全获取自己的 shared_ptr |
| **std::any** | TcpConnection | 类型安全的 void*，存储任意类型上下文 |
| **Meyer's Singleton** | MemoryPool, Logger | C++11 线程安全的单例实现 |
| **= delete** | Buffer, Socket, ThreadPool | 禁止拷贝，防止意外复制资源 |
