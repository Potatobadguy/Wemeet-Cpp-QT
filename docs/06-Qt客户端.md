## 1. main.cpp — 暗色主题入口

**文件**：`main.cpp`（39行）

### QSS 内嵌暗色主题

```cpp
static const char* kDarkTheme = R"(
QMainWindow, QDialog, QWidget {
    background-color: #0a0a1a; color: #e0e0e0;
}
QPushButton {
    background-color: #2a2a3e; color: #e0e0e0;
    border: none; border-radius: 6px; padding: 8px 16px;
}
QPushButton:hover { background-color: #3a3a5e; }
QLineEdit, QTextEdit {
    background-color: #16213e; color: #e0e0e0;
    border: 1px solid #2a2a4e; border-radius: 6px; padding: 8px;
}
QLineEdit:focus { border-color: #4A90D9; }   /* 聚焦高亮 */
QListWidget {
    background-color: #111122;
    border: 1px solid #2a2a3e; border-radius: 8px;
}
QListWidget::item:selected { background-color: #4A90D9; color: white; }
QScrollBar:vertical { background: #0a0a1a; width: 8px; }
QScrollBar::handle:vertical { background: #3a3a5e; border-radius: 4px; }
)";
```

QSS 是 Qt 的样式表语言，语法和 CSS 高度相似。内嵌主题的优势：不需要外部 `.qss` 文件，一个可执行文件就是完整的带主题的应用。

### 应用程序入口

```cpp
int main(int argc, char* argv[]) {
    QApplication app(argc, argv);           // Qt 应用程序对象（必须第一个创建）
    app.setStyleSheet(kDarkTheme);          // 全局应用暗色主题

    MainWindow window;                      // 主窗口
    window.setWindowTitle("WeMeet — 企业级视频会议");
    window.resize(1200, 800);
    window.show();                          // 显示窗口

    return app.exec();                      // 进入事件循环（消息泵）
}
```

`app.exec()` 进入 Qt 的事件循环，类似 `EventLoop::loop()`。窗口事件、鼠标点击、网络数据都通过事件循环分发。

## 2. MainWindow — 页面切换

**文件**：`main_window.h` + `main_window.cpp`

### 堆叠布局切换页面

```
MainWindow
├── QStackedWidget (页面容器)
│   ├── LoginDialog   (index 0 — 登录页)
│   └── MeetingRoom   (index 1 — 会议室页)
└── QStatusBar (底部状态栏)
```

```cpp
// 登录成功 → 切换到会议室
stacked_widget_->setCurrentIndex(1);

// 退出登录 → 切换回登录页
stacked_widget_->setCurrentIndex(0);
```

### 信号槽连接

```cpp
// 登录成功信号 → 页面切换槽
connect(login_dialog_, &LoginDialog::login_success,
        this, &MainWindow::on_login_success);

// 退出信号 → 回登录页
connect(meeting_room_, &MeetingRoom::logout,
        this, &MainWindow::on_logout);
```

**信号槽是 Qt 的核心机制**：对象间通信的解耦方式。`LoginDialog` 发信号时不知道谁在听，`MainWindow` 的槽也不知道信号从哪来，两者通过 `connect` 绑定。这比直接回调更灵活——一个信号可以连接多个槽，也可以跨线程。

### 信号定义

```cpp
class LoginDialog : public QDialog {
    Q_OBJECT   // Qt 元对象系统宏（必须，启用信号槽）
signals:
    void login_success(const QString& email, const QString& token,
                        const QString& nickname);
};
```

`Q_OBJECT` 宏让 Qt 的 moc（元对象编译器）为这个类生成信号槽所需的元数据。

### 异步网络调用

```cpp
void LoginDialog::on_login_clicked() {
    // 连接网络客户端
    network_client_ = new NetworkClient(this);
    network_client_->connectToServer("127.0.0.1", 9090);

    // 连接信号：收到登录响应
    connect(network_client_, &NetworkClient::login_result,
            this, &LoginDialog::on_login_result);

    // 发送登录请求（异步，不阻塞 UI）
    network_client_->sendLogin(email, password);
}
```

**为什么是异步**：如果用同步阻塞方式调用网络（等服务器返回才继续），UI 会卡死。异步方式：发请求后立即返回，收到响应时通过信号通知，UI 始终保持响应。

## 5. NetworkClient — TCP 网络通信

**文件**：`network_client.h` + `network_client.cpp`

### QTcpSocket 异步通信

```cpp
class NetworkClient : public QObject {
    Q_OBJECT
public:
    void connectToServer(const QString& host, quint16 port) {
        socket_->connectToHost(host, port);          // 异步连接
    }

    void sendLogin(const QString& email, const QString& password) {
        LoginReq req;
        req.set_email(email.toStdString());
        req.set_password(password.toStdString());

        auto buf = Codec::encode_wrapped(MSG_LOGIN_REQ, next_seq_id_++, req);
        socket_->write(reinterpret_cast<const char*>(buf.data()), buf.readable_size());
    }

signals:
    void login_result(bool success, const QString& token, const QString& nickname);
    void meeting_created(const QString& room_id);
    void chat_received(const QString& user, const QString& content);

private slots:
    void on_ready_read() {
        // 读数据 → 解长度头 → 解 BaseMessage → 根据 type 发信号
    }
};
```

### 客户端网络模型

```
NetworkClient
├── QTcpSocket (TCP 长连接)
│   ├── connected() → 信号
│   ├── readyRead() → 槽：读数据 → 解码 → 发业务信号
│   └── disconnected() → 清理状态
├── Buffer (输入缓冲，处理粘包)
└── next_seq_id_ (请求序号，匹配响应)
```

### 信号驱动的 UI 更新

```cpp
// 收到消息 → 更新 UI（线程安全，因为 NetworkClient 在主线程）
connect(network_client_, &NetworkClient::chat_received,
```
