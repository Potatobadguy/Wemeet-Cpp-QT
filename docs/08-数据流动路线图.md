# 08 数据流动路线图

> 本文档展示了每个子系统内部及之间的数据流向。建议在各阶段学习完成后回来看对应的流程图。

---

## 1. 登录流程（客户端 ↔ 服务器 ↔ 数据库）

```
┌─ 客户端 ─────────────────────────────────────────────────────────────────┐
│                                                                          │
│  [用户输入邮箱+密码]                                                       │
│       │                                                                  │
│       ▼                                                                  │
│  NetworkClient::sendLogin(email, password)                               │
│       │                                                                  │
│       ▼                                                                  │
│  LoginReq 序列化 ──▶ BaseMessage(payload) ──▶ Codec::encode_wrapped()    │
│       │                                                                  │
│       ▼                                                                  │
│  QTcpSocket::write( [4B长度头][BaseMessage二进制] )                       │
│       │                                                                  │
└───────┼──── TCP ──────────────────────────────────────────────────────────┘
        │
        ▼
┌─ 服务器 ─────────────────────────────────────────────────────────────────┐
│                                                                          │
│  epoll_wait() 返回 fd 可读                                                │
│       │                                                                  │
│       ▼                                                                  │
│  TcpConnection::handle_read()                                            │
│       │  read(fd) → Buffer(read_buf_)                                    │
│       ▼                                                                  │
│  Codec::peek_length() → 读4字节长度头 → 等够 body 长度                     │
│       │                                                                  │
│       ▼                                                                  │
│  Codec::decode_base_message() → BaseMessage {type, seq_id, payload}       │
│       │                                                                  │
│       ▼                                                                  │
│  SignalingServer::on_message(conn, buf)                                   │
│       │  switch(base.type())                                             │
│       │  case MSG_LOGIN_REQ: → handle_login()                            │
│       ▼                                                                  │
│  Codec::decode_payload(base, LoginReq)                                   │
│       │                                                                  │
│       ▼                                                                  │
│  AuthService::login(email, password, conn_id)                             │
│       │                                                                  │
│       ├──▶ user_repo_.find_by_email(email)                               │
│       │        │                                                         │
│       │        ▼                                                         │
│       │    ConnectionPool::borrow() → MYSQL*                              │
│       │        │                                                         │
│       │        ▼                                                         │
│       │    mysql_stmt_execute("SELECT ... WHERE email=?")                 │
│       │        │                                                         │
│       │        ▼                                                         │
│       │    ConnectionPool::return(conn)  ← RAII 自动归还                  │
│       │        │                                                         │
│       │        ▼                                                         │
│       │    std::optional<User> → 返回                                     │
│       │                                                                  │
│       ├──▶ hash_password(input) == user.password_hash  (SHA256验证)      │
│       │                                                                  │
│       ├──▶ generate_token(user_id) → "hex_id_random1_random2"            │
│       │                                                                  │
│       └──▶ user_mgr_->add_session({user_id, token, conn_id})              │
│                                                                          │
│       ▼                                                                  │
│  LoginResp {success, user_id, token, nickname}                            │
│       │                                                                  │
│       ▼                                                                  │
│  Codec::encode_wrapped(MSG_LOGIN_RESP, seq_id, resp) → Buffer            │
│       │                                                                  │
│       ▼                                                                  │
│  conn->send(Buffer&&)  ← 移动语义零拷贝                                   │
│       │                                                                  │
└───────┼──── TCP ──────────────────────────────────────────────────────────┘
        │
        ▼
┌─ 客户端 ─────────────────────────────────────────────────────────────────┐
│                                                                          │
│  QTcpSocket::readyRead() → 读数据                                         │
│       │                                                                  │
│       ▼                                                                  │
│  Codec::peek_length() → Codec::decode_base_message()                     │
│       │                                                                  │
│       ▼                                                                  │
│  switch(type) case MSG_LOGIN_RESP:                                       │
│       │                                                                  │
│       ▼                                                                  │
│  Codec::decode_payload(base, LoginResp)                                  │
│       │                                                                  │
│       ▼                                                                  │
│  emit login_result(success, token, nickname)                             │
│       │                                                                  │
│       ▼                                                                  │
│  MainWindow::on_login_success() → 更新UI → 切换到大厅页                    │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

> **涉及模块**：协议层(02)、网络框架(03)、数据库层(04)、信令服务器(05)、Qt客户端(06)

## 2. 网络层数据流（Buffer → 协议 → epoll）

```
  客户端发送                    服务端接收
  ─────────                    ─────────

  LoginReq{email, password}
       │
       ▼
  SerializeAsString() ──▶ string body
       │
       ▼
  BaseMessage{type=100, payload=body}
       │
       ▼
  SerializeAsString() ──▶ string msg
       │
       ▼
  [htonl(len)] [msg bytes]   ← 4字节长度头 + body
       │                              │
       ▼                              ▼
  socket.write()  ──TCP──▶  epoll_wait 返回可读
                                   │
                                   ▼
                              Buffer::append(read数据)
                                   │
                                   ▼
                              读够4字节 → ntohl(len)
                                   │
                                   ▼
                              等 body 读足 len 字节
                                   │
                                   ▼
                              ParseFromArray() → BaseMessage
                                   │
                                   ▼
                              根据 type 反序列化 payload
                              → LoginReq
```

> **涉及模块**：通用工具库(01 — Buffer)、协议层(02 — Codec)、网络框架(03 — EventLoop)

## 3. 内存流动（MemoryPool + Buffer + 无锁队列）

```
  线程A (网络IO)                       线程B (业务处理)
  ────────────                        ────────────

  MemoryPool::allocate(SMALL)
       │
       ▼
  tls_pool_.free_lists[SMALL]
       │
       ├── 有空闲 → pop_back() 返回 (池命中: +1)
       │
       └── 无空闲 → aligned_alloc(64, 8KB)  (系统调用)
       │
       ▼
  void* buf (8KB 缓存行对齐)
       │
       ▼
  TcpConnection::handle_read()
       │  read(fd, buf, ...)
       ▼
  Buffer::append(buf, len)  ──▶  read_buf_ 填满
       │
       ▼
  Codec 解码 → BaseMessage
       │
       ▼
  ┌─────────────────────────────────────────┐
  │  SPSCQueue::try_push(BaseMessage)       │
  │       │                                 │
  │       ▼                                 │
  │  buffer_[write & mask_] = msg           │  ← 无锁写入
  │  write_pos_.store(next, release)        │
  └──────────────┬──────────────────────────┘
                 │
                 ▼
  ┌─────────────────────────────────────────┐
  │  SPSCQueue::try_pop(BaseMessage)        │
  │       │                                 │
  │       ▼                                 │
  │  read = read_pos_.load(acquire)          │  ← 无锁读取
  │  if read == write_pos_ → 空              │
  │  msg = buffer_[read & mask_]            │
  │  read_pos_.store(read+1, release)       │
  └──────────────┬──────────────────────────┘
                 │
                 ▼
  SignalingServer::on_message(conn, buf)
       │
       ▼
  AuthService::login(...) → MySQL → 返回结果
       │
       ▼
  Codec::encode_wrapped(...) → Buffer(移动构造)
       │
       ▼
  conn->send(Buffer&&)  ← 移动语义零拷贝发送
       │
       ▼
  MemoryPool::deallocate(buf, SMALL)
       │
       ▼
  tls_pool_.free_lists[SMALL].push_back(ptr)  ← 归还池
```

> **涉及模块**：通用工具库(01 — MemoryPool, LockFreeQueue, Buffer)

## 4. WebRTC 信令转发流（SDP/ICE 中继）

```
  客户端A                          服务器(信令)                      客户端B
  ────────                        ────────────                     ────────

  RTCPeerConnection
  .createOffer()
       │
       ▼
  SDP文本 (几千字节)
       │
       ▼
  SDPOffer{from=A, to=B,
           room_id, sdp}
       │
       ▼
  encode_wrapped() ──TCP──▶  on_message()
                                   │
                                   ▼
                              handle_sdp_offer()
                                   │
                                   ▼
                              找到 B 的 conn_id
                              (通过 user_manager_)
                                   │
                                   ▼
                              TcpServer 找到 B 的
                              TcpConnection
                                   │
                                   ▼
                              conn_B->send(SDPOffer)
                                   │
                              ────TCP──▶  收到 SDP Offer
                                                │
                                                ▼
                                          RTCPeerConnection
                                          .setRemoteDescription(sdp)
                                                │
                                                ▼
                                          .createAnswer()
                                                │
                                                ▼
                                          SDPAnswer 发回服务器
                                                │
                                          ────TCP──▶  转发给A

  (ICE Candidate 同理，双向中继)
```

> ⚠️ 信令服务器只转发 SDP/ICE 文本，**不处理音视频数据**。音视频是客户端之间 P2P 直连。

> **涉及模块**：协议层(02)、网络框架(03)、信令服务器(05)、Qt客户端(06)

## 5. 聊天消息广播流

```
  客户端A                      服务器                        客户端B/C/D...
  ───────                     ──────                        ───────────

  ChatSend{user_id=A,
           room_id,
           content="Hello"}
       │
       ▼
  encode_wrapped() ──TCP──▶  handle_chat()
                                   │
                                   ▼
                              ChatReceive{user_id=A,
                                          content, timestamp}
                                   │
                                   ▼
                              encode_wrapped()
                                   │
                                   ▼
                              tcp_server_->broadcast()
                                   │
                                   ▼
                          ┌───────┼───────┐
                          ▼       ▼       ▼
                        客户端B 客户端C  客户端D
                          │       │       │
                          ▼       ▼       ▼
                    收到消息 → 更新聊天面板UI
```

> **涉及模块**：协议层(02)、网络框架(03 — TcpServer::broadcast)、信令服务器(05)、Qt客户端(06)

## 6. 线程模型数据流（One Loop Per Thread）

```
  main_loop_ (主Reactor)              worker_loop_0 (子Reactor)    worker_loop_1
  ─────────────────────               ──────────────────────       ────────────

  epoll_wait(listen_fd)
       │ accept() 新连接
       ▼
  Socket conn_sock (移动语义转移)
       │
       ▼
  pool_->next_loop()  ──轮询──▶  返回 worker_loop_0
       │                                │
       ▼                                ▼
  make_shared<TcpConnection>      注册 conn_fd 到 epoll
  (worker_loop_0, sock, id)            │
       │                                ▼
       ▼                          epoll_wait 等待
  设置回调:                              │
  - message_cb_ = on_message        conn_fd 可读/可写
  - close_cb_ = 从分片表移除              │
       │                                ▼
       ▼                           handle_read()
  shards_[id%16].connections       → Buffer 读数据
  [id] = conn                      → Codec 解码
       │                           → on_message(conn, buf)
       ▼                           → 业务处理
  conn->start()                    → encode 响应
       │                           → conn->send()
       ▼                                │
  注册到 worker_loop_0 的 epoll         ▼
                                  epoll_wait 继续...
```

> **涉及模块**：网络框架(03 — EventLoop, EventLoopPool, TcpServer)

## 7. 完整请求生命周期

```
用户操作 → UI控件 → 信号/槽 → NetworkClient → Protobuf编码
    │                                                    │
    │                                                    ▼
    │                                            QTcpSocket/TCP发送
    │                                                    │
    │                              ┌─────────────────────┘
    │                              ▼
    │                         epoll ET 唤醒
    │                              │
    │                              ▼
    │                         TcpConnection::handle_read()
    │                              │
    │                              ▼
    │                         Codec 解码 (长度头 → BaseMessage → 子消息)
    │                              │
    │                              ▼
    │                         SignalingServer::on_message()  ← switch分发
    │                              │
    │                    ┌─────────┼─────────┐
    │                    ▼         ▼         ▼
    │              AuthService  Meeting   Signaling
    │                    │         │         │
    │                    ▼         ▼         ▼
    │              ConnectionPool::borrow()  user_manager_
    │                    │
    │                    ▼
    │              MySQL Prepared Statement
    │                    │
    │                    ▼
    │              ConnectionPool::return()  ← RAII自动归还
    │                    │
    │                    ▼
    │              构造响应 (LoginResp/MeetingResp...)
    │                    │
    │                    ▼
    │              Codec::encode_wrapped() → Buffer (移动语义)
    │                    │
    │                    ▼
    │              conn->send(Buffer&&) → write_buf_
    │                    │
    │              ┌─────┘
    │              ▼
    │         TCP发送回客户端
    │              │
    └──────────────┘
                   ▼
            QTcpSocket::readyRead()
                   │
                   ▼
            Codec 解码 → 发信号 → UI更新
```

> **涉及模块**：全部模块串联
